💡 ARC Companion App Features

Complete Blueprint Tracker: Track 156+ ARC Raiders blueprints with real-time status (learned, in inventory, unknown). Filter by rarity, station, or search by name.

Map Conditions: Real-time display of raid conditions on all maps. Target-specific blueprints only drop under certain conditions (Night Raid, EM Storm, Closed Gate, Hidden Bunker, Harvester, Stella-bound, Quest).

Steam Integration: Load blueprint data directly from your Steam account. Automatic sync of learned blueprints and inventory status.

Progress Tracking: Visual progress bars showing completion percentage. Breakdown by rarity (Common, Uncommon, Rare, Epic, Legendary). Track inventory vs learned blueprints.

Comprehensive Guides: Container types with drop rates, map conditions, farming strategies, early-game priority list, and pro tips.

Dark & Light Themes: Toggleable themes with hand-tuned color palettes. Dark mode optimized for night gaming sessions. Light mode for daytime use.

Persistent Storage: Local storage saves all progress. Data persists across sessions. Manual reset option available.

Responsive Design: Mobile-first design works on phones, tablets, and desktop. Clean, minimal UI with focus on readability.
